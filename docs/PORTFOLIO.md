# Fiche portfolio

## Retail Core Lakehouse

Plateforme Data Engineering omnicanale simulant les flux retail d’un acteur de la mode.

**Problème métier :** rapprocher les ventes web/magasin, les événements temps réel et les stocks pour fournir des indicateurs fiables et réduire le risque de rupture.

**Résultat :** pipeline reproductible calculant les ventes, le Customer 360, le stock disponible à la vente et un contrôle automatique de réconciliation batch/streaming.

**Technologies :** Python, SQL, SQLite (prototype warehouse), fichiers data lake Raw/Curated, Airbyte/Kinesis/AWS/Snowflake/dbt/Airflow (équivalents d’architecture documentés).

**Compétences visibles :** modélisation dimensionnelle, qualité des données, ingestion, orchestration, observabilité, logique métier retail et optimisation progressive vers le cloud.
